# SyncSpace

## Real-Time Team Collaboration Platform

SyncSpace is a scalable real-time collaboration platform designed for teams to manage projects, tasks, communication, files, and team activity from a unified workspace.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Redis
- WebSockets

### Infrastructure
- Docker
- AWS
- AWS Application Load Balancer
- AWS S3

## Core Features

- Authentication
- Workspaces
- Role-Based Access Control
- Teams
- Projects
- Tasks
- Kanban Board
- Comments
- Mentions
- Notifications
- Activity Feed
- Real-Time Collaboration
- User Presence
- File Uploads
- Global Search
